# tailwind-css-multiple-theme-dynamic

Next.js + Tailwind CSS로 멀티 테마를 동적 전환하는 예제

CSS 변수 + `data-theme`으로 테마를 정의하고, Context로 상태를 공유한 뒤 `localStorage`에 저장해서 새로고침해도 유지됩니다.
